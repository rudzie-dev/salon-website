# Queens Corner Glam

Static website for Queens Corner Glam (braids, dreadlocks, wigs, lashes). No build step.

## Quick edits
- Edit `index.html` on GitHub (pencil icon), commit, and Vercel redeploys in about 30 seconds.
- Colours and fonts are the variables at the top of the `<style>` block (`--accent`, `--ink`, `--bg`).

## Uploading photos
1. Open the `img/` folder on GitHub, choose **Add file > Upload files**, and commit.
2. To swap a photo, upload one with the same file name (`hero.jpg`, `braids.jpg`, `locs.jpg`, `wig1.jpg`, `wig2.jpg`, `lashes.jpg`).
3. For a new photo, upload it, then point an `<img src="img/yourfile.jpg">` at it in `index.html`.
Keep photos under about 500 KB (JPG, up to 1400px wide) so the page loads fast.
